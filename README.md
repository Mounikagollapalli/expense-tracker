# Quarterly Expenses Report

A simple expense-tracking project for recording transactions and reviewing income and expenses across a quarter.

## Overview

The Quarterly Expenses Report helps users keep track of their financial activity in one place. It presents key expense information in a clear dashboard-style layout.

## Features

- Add and review transaction details
- Record transaction dates, amounts, and types
- View total balance
- View credited and debited amounts
- Review quarterly expense information in an organized report

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap / Tailwind CSS (depending on the project version)

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Mounikagollapalli/expense-tracker.git
   ```
2. Open the project folder.
3. Open the main HTML file in your browser.
